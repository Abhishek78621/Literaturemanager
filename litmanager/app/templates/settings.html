AI Provider (optional)

Used only for: classifying/summarizing new papers on import, and "Reason across papers" search mode. Everyday browsing and "Find papers" search never call this API. Leave everything blank to run fully offline for $0.

Free options: pick OpenAI-compatible (local/free) below and point it at:
• Ollama running on your own PC — 100% free, no key, no internet needed once the model is downloaded. Base URL: http://localhost:11434/v1/chat/completions, model e.g. llama3.
• Groq — free tier, cloud-hosted, fast. Base URL: https://api.groq.com/openai/v1/chat/completions, needs a free Groq API key.
• OpenRouter — some models are free. Base URL: https://openrouter.ai/api/v1/chat/completions, needs a free OpenRouter key, model e.g. meta-llama/llama-3-8b-instruct:free.
